# Istawra Services — public client website

English-language client website at https://istawra.com. Static HTML, CSS and progressive reading tools; GitHub Pages publishes the main branch root.

## Client pages

Home; Services and engagement formats; Public sector; Investment; Approach; Academy; Insights and its white paper; About; Contact. Advisory principles are linked from Approach. Legacy routes redirect to current pages.

## Content boundaries

The partner/investor site and local command system are separate projects. Do not add private proposals, client records or internal review notes here. This repository and its existing history are public. Removing a live page does not remove historical copies.

SaudiOpp is under development. Keep the existing contact email until the branded mailbox is activated and delivery verified. Do not publish draft case vignettes without disclosure clearance.

## Local preview

Run `python3 -m http.server 4190 --bind 127.0.0.1` from this directory. Check navigation, local links and narrow-screen layout before publishing.
