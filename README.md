# Istawra Services — public client website

English and Arabic client website at https://istawra.com. Static HTML, CSS and an interactive investor explorer; GitHub Pages publishes the main branch root. Arabic pages are under `/ar/`.

## Client pages

Home; About; four service pillars; five visitor journeys; Approach; Insights with 11 readings; Careers; Contact; Privacy and Terms. Legacy URLs redirect to the relevant current pages.

## Release status

The owner authorised publishing this review version for sharing. Privacy and Terms remain explicitly labelled incomplete drafts. Search indexing remains disabled pending final readiness. Automated content and local-link checks passed; a rendered desktop/mobile review was not completed before this release.

## Content boundaries

The partner/investor site and local command system are separate projects. Do not add private proposals, client records or internal review notes here. This repository and its existing history are public. Removing a live page does not remove historical copies.

The sole public contact is engage@istawra.com, handled by Mohammed Almajed. Do not publish draft case vignettes without disclosure clearance.
